## 🚀 Краткие параметры формата
* **Целевой рынок:** Англоязычный (США и Global YouTube).
* **Периодичность:** 1 выпуск раз в 2 недели (26 эпизодов в год).
* **Хронометраж:** 25–35 минут (оптимум Watch Time и 3–4 рекламных слота).
* **Ядро команды:** Ведущий/сценарист + Research Producer + Удаленный видеомонтаж/AI + Пул экспертов.
* **Себестоимость эпизода:** ~$1,000 – $1,400 (софтверный стек ~$150/мес).
